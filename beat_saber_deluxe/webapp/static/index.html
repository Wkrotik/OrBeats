      Custom batch file format (for hand-editing)
      
Custom batches are plain JSON files — editable in any text
      editor on Windows, macOS, or Linux. Save them from this tab (or create your
      own) with this structure:

      
{
  "format": "bsd-batch",
  "version": 1,
  "name": "My 80s pack",
  "description": "optional free text",
  "songs": [
    {
      "map_id": "c213",            // BeatSaver map ID (required)
      "target": "Angry",           // stock slot to replace (required)
      "song_name": "Rhythm Is A Dancer",   // optional display label
      "artist": "Pegboard Nerds",          // optional display label
      "audio": "pcm16",            // pcm16 (default) | vorbis | hevag
      "pad_fsb5": false,           // keep false (true truncates long songs)
      "convert_to_v3": true        // the recommended default
    }
  ]
}

      
Saved batches live in webapp/batches/ — or
      use Export/Import on this tab to move them between machines as files
      (works everywhere; nothing depends on server-side paths).

Get Started — full point-and-click in 5 steps

    
This hosted page is the planning surface: search songs, build
    batches, learn the dump process, and generate exact commands. To actually
    deploy to your PS4 you need the app running on the machine that has
    your ps4_dump/ folder and can reach the PS4 — this page guides
    you there in a couple of minutes.


    

      

        
1 · Check your prerequisites

        
    
          
  •  Python 3.8+ on the deploy machine
            (check: python3 --version)
    • 
          
  •  A jailbroken PS4 with GoldHEN, FTP enabled (port 2121)
    • 
          
  •  Beat Saber v2.04 (CUSA12878) with patch 2.04 installed
    • 
          
  •  No game dump needed! The plugin's built-in
            game-data extractor retrieves the files for your chosen packs during a normal
            boot — see the Dump Guide's 5-step walkthrough.
            (A decrypted ps4_dump/ is only needed for development/repair.)
    • 
          
  •  Both machines on the same network
    • 
        

      


      

        
2 · Download the release

        
One zip contains everything: the pipeline, the plugin (pre-built,
        release + debug), this web app, all docs.

        

          Download the latest release ↗

        beat-saber-deluxe-*.zip file. (This link always points at the
        newest stable release.)

Game Dump Guide

    
OrBeats replaces songs in your own copy of the game —
    it never distributes game content.


    

      
✨ Option A — Let the game extract it (recommended; no dump needed)

      
The plugin copies the exact files the pipeline needs (per-slot
      templates, pack bundles, the catalog) out of the game's own data during a
      normal boot — you never make or hold a decrypted dump on this PC.
      Legally clean: everything is extracted from your own console.


      

        
STEP 1 · Request the data

        
Pick the packs you want extracted (or Select all), then
        press the button. The plugin extracts on by default — nothing to arm.

        

          
          
          
        

        

        
      


      

        
STEP 2 · Launch Beat Saber on your PS4

        
A normal boot is all it takes — the plugin extracts
        during startup and shows a PS4 notification ("BSD: game data
        ready") when finished. This page is watching and updates
        automatically. (Failures retry on the next boot.)

      


      

        
STEP 3 · Pull the extracted files here

        
After the notification, come back and press the button.
        Watch the progress bar fill as the files copy to this PC.

        

          

          0%
        

        
      


      

        
STEP 4 · Save the cache for the web app

        
One press points the pipeline at the extracted
        cache — from here on, every song build uses it. No dump anywhere.

        
      


      

        
STEP 5 · Deploy songs 🎉

        
Go to Find a Song & Deploy
        — pick any BeatSaver song, target any slot in your extracted packs,
        and deploy. Everything builds from the cache.

Option B — I already have a decrypted dump (the classic recipe)

      
You need a decrypted dump of Beat Saber CUSA12878
      patch 2.04 on this machine. Only needed for development/repair —
      Option A covers everything else.


    

      
What you need

      
    
        
  • A jailbroken PS4 with GoldHEN (the same setup the plugin requires).
    • 
        
  • Beat Saber v2.04 (CUSA12878) with patch 2.04 installed.
    • 
        
  • The music packs you want to modify, installed BEFORE dumping —
            their bundles live in the patch dump. Installing DLC after dumping is the
            #1 setup problem.
    • 
        
  • A USB stick with enough free space (the dump is several GB).
    • 
      

    


    

      
The recipe

      
    
        
  1. Download dumper.cfg
            and copy it to the root of your USB stick.
            It sets split=3: app and patch are dumped into
            separate CUSA12878-app/ and CUSA12878-patch/ folders.
            
    What each line means
              
    ; 0 — one combined folder     (don't use)
; 1 — app only
; 2 — patch only
; 3 — app AND patch, split folders  ← what we want
split=3

; Progress notification every 30 s
notify=30

; Shut the console down when done
shutdown=1
    
            
    2. 
        
  2. With the USB stick inserted, run the dumper homebrew (GoldHEN → PS4 Dumper).
    3. 
        
  3. Copy both CUSA12878-app/ and CUSA12878-patch/
            from the stick into a ps4_dump folder on this machine — or just
            point the wizard at wherever you put them.
    4. 
        
  4. Back in the Setup Wizard, validate the folder:
            it should report patch 2.04 contents, eboot.bin,
            the origin catalog, and a confidence list of found DLC packs.
    5. 
      

      
Useful links: GoldHEN
      · PS4 Dumper (Al-Azif)
      · the release README's Prerequisites section.

    


    

      
If validation fails

      
    
        
  • No -app/-patch split — your dumper.cfg wasn't
            on the stick root or lacked split=3.
    • 
        
  • Patch dump missing eboot.bin/Media/ — the dumper
            produced packed blobs instead of unpacked files; re-dump with a current dumper.
    • 
        
  • No DLC packs found — install the packs on the PS4 first, then dump again.
    • 
        
  • Wrong game version — this pipeline targets patch 2.04 specifically.
    •
