# OrBeats 0.1.15 — import compatibility patch

## Downloads

- **Windows x64:** `OrBeats_0.1.15_x64-setup.exe` — download the EXE itself, no ZIP.
- **Linux x64:** `OrBeats_0.1.15_amd64.AppImage` — mark executable before running.
- The desktop already includes main plugin **0.8079** and optional Extras
  **0.0009**. Separate PRXs remain available for manual setup; existing users
  do not need to reinstall unchanged plugins for these importer fixes.

## Fixes

- Accept reviewed basic lighting-event types 16–19, fixing Borderline (BeatSaver
  `365ca`) and similarly authored charts. Rotation/special/BPM/NJS types remain
  excluded from ordinary lighting. Authored notes, arcs, chains and lighting
  are preserved rather than discarded to make an import succeed.
- Include FFmpeg's raw PCM muxer, correcting failures during preserved 48 kHz
  Vorbis verification. Media builds now test actual pipe/resampling output;
  frozen-helper checks cover both 44.1 and 48 kHz using bundled tools.
- Include the compact connection/Updates layout previously committed to the
  repository. Pagination remains horizontal below the song results; the
  experimental navigation card is not included.

Desktop **0.1.15**, companion **0.7.31**, pipeline **0.5394**. Local-only desktop
0.1.14 was not a public release. The owner confirmed Borderline works with the
corrected Linux candidate, map installation works, and in-app previews play.

## Supporting files explained

Normal users only need their EXE or AppImage. Other downloads have separate roles:

- `release-manifest.json`: small machine-readable feed required by **Check
  updates** and explicit plugin download size/hash/version checks. Do not delete
  or hand-edit it as a workaround for update failures.
- `SHA256SUMS`: checksums for verifying complete, unchanged downloads. These are
  not digital signatures and do not make an unsigned app trusted or certified.
- `OrBeats_0.1.15_sources-notices.tar.gz`: consolidated third-party sources,
  notices, rebuild/relink information and build provenance. This replaces the
  previous separate notices, system-source, language/media-source and provenance
  downloads without removing their material. No game data, maps or private
  project/console files are included. Application source is at the release tag.

## Testing limits and known warnings

Both desktop builds are unsigned. Automated native Windows build/backend/media
checks do not establish interactive Windows install/upgrade/uninstall or GUI
behavior; a hands-on Windows test has not been performed for this patch. Report
platform-specific problems using the repository's issue forms.

Linux runtime/ABI/offline-conversion checks and the owner's working setup are
not a claim of compatibility with every distro, display server or audio device.
GTK cursor/accessibility and WebKit GStreamer WebVTT/fakevideosink warnings were
reported on a working Linux setup. Preview audio works there; this patch does
not claim to resolve those optional-plugin/integration warnings.

Keep Beat Saber fully closed for library/plugin writes. Desktop upgrades remain
manual, no downloaded executable is silently launched, and the app never starts
the game for you. Existing source and third-party licence terms still apply.
