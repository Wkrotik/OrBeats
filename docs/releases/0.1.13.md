# OrBeats 0.1.13

## Downloads

- **Windows x64:** `OrBeats_0.1.13_x64-setup.exe` — the installer itself, no ZIP.
- **Linux x64:** `OrBeats_0.1.13_amd64.AppImage` — mark executable before running.
- **Main plugin:** `orbeats.prx` 0.8079.
- **Optional Extras:** `orbeats_extras.prx` 0.0009; requires the main plugin.

If WebView2 is absent, the Windows bootstrapper requires internet to obtain the
Microsoft runtime.

The desktop bundles both plugins; separate PRXs are available for manual use.
Notices, corresponding source material, provenance, checksums and the update-feed
manifest are separate developer/support downloads. They are not required to wrap
or extract the Windows installer.

## What's new

- Install/check Extras from the app without replacing the main plugin or song
  library. Existing health settings are preserved; restart the closed game after
  installation. Extras provides optional health-warning dismissal and anonymous,
  read-only top-ten ScoreSaber results for supported custom Standard maps.
- Check the official GitHub repository for app/main-plugin/Extras updates. An
  unavailable network/feed is reported honestly, not as "up to date". Installing a
  plugin update is explicit and verifies its manifest size, SHA-256 and version.
  Desktop replacement is manual; no downloaded executable is silently run.
- Hide the bootstrap window until the authenticated app is ready. Closing hides
  both webviews while active backend work finishes safely. Suppress Windows child
  process console windows. Stabilize the Linux sidebar during aggressive scrolling.
- Remove redundant sidebar text/theme switching; theme controls remain in Settings.
- Preserve dependency notices and source provenance in the distribution material.

The converter includes the previously confirmed Animals Hard/lighting repair.
Older songs without original map identity need reimport for ScoreSaber matching.
Scores are read-only: no login, credential collection, score submission or tracking
agreement bypass is added.

## Requirements and cautions

Only the supported Beat Saber PS4 title/build described in
[getting started](../getting-started.md) is supported. Keep the game closed during
plugin/library installation. Preserve local recovery archives and check the
console's address before any write. This release does not install or launch a game
automatically.

These are early **unsigned** desktop builds. Windows native CI tests passed, but
interactive installer/upgrade/uninstall and physical Windows GUI behavior are not
claimed as tested. Linux launch/close/offline conversion passed in an isolated
Ubuntu 22.04 userspace; broader FUSE/Wayland/audio/distro testing remains open.
See [release evidence and limits](../public-release-checklist.md).

Verify `SHA256SUMS` against the actual downloads. Checksums help detect altered or
incomplete downloads; they do not turn an unsigned build into a certified one.
