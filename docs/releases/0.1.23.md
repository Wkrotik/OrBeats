# OrBeats 0.1.23

More faithful map imports, faster library management, and clearer setup and compatibility checks.
This release includes the tested changes from the 0.1.21–0.1.23 development candidates.

**[Windows installer](https://github.com/Wkrotik/OrBeats/releases/download/v0.1.23/OrBeats_0.1.23_x64-setup.exe)** · **[Linux AppImage](https://github.com/Wkrotik/OrBeats/releases/download/v0.1.23/OrBeats_0.1.23_amd64.AppImage)** · **[Installation / first-time setup](https://github.com/Wkrotik/OrBeats/blob/main/docs/getting-started.md)**

## What changed

- Support validated InfoV4 hexadecimal RGBA palettes and editor metadata, high-BPM
  timing changes, signed arc tangents, and independently rounded audio sample
  endpoints. Preserve authored chart timing and geometry; unsupported mod effects
  still refuse rather than being silently removed.
- Recognize an already-installed BeatSaver revision before conversion only after
  checking its provenance, installed files and stable library. Reuse the
  setup-validated local conversion template instead of repeatedly downloading it.
- Remove a confirmed selection in one locked library update, then clean up only
  its owned files. Keep writes serialized and report incomplete cleanup.
- Hide known-incompatible search results while keeping unknown maps visible.
  Details can download and check wall geometry without installing anything;
  results are tied to the exact map revision. Unsupported PS4 wall layers retain
  an explicit refusal, not a geometry-changing workaround.
- Bound menu previews within the audio without changing gameplay audio or timing.
  Explain unsupported geometry/lighting, mod dependencies and retained score
  identity conflicts without overwriting existing scores.
- Existing profiles with completed imports open Discover without claiming a
  validated conversion template. Pending extraction restoration still forces
  Setup. Improve checkbox alignment and its desktop/mobile click target.
- Finish OrBeats branding cleanup and remove the misleading sidebar web-interface
  version label. Version checks remain in Settings.

## Versions and downloads

Desktop **0.1.23**, web interface **0.7.40**, pipeline **0.5403**.
Main **0.8079** and Extras **0.0015** are unchanged and bundled with both apps;
separate PRX files are available for manual management. Windows installers remain
unsigned. Normal users do not need the sources/notices archive.

Requires **CUSA12878 / patch 2.04**, GoldHEN plugin support and FTP. Fully close
Beat Saber for writes. OrBeats never launches/closes the game for you, bundles
proprietary game assets, replaces stock/DLC songs or bypasses entitlements.
