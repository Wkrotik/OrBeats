# OrBeats 0.1.20

Guided first-time setup, clearer progress and recovery, and the Bottles startup fix.
This release includes the tested changes from the 0.1.17–0.1.20 development candidates.

**[Windows installer](https://github.com/Wkrotik/OrBeats/releases/download/v0.1.20/OrBeats_0.1.20_x64-setup.exe)** · **[Linux AppImage](https://github.com/Wkrotik/OrBeats/releases/download/v0.1.20/OrBeats_0.1.20_amd64.AppImage)** · **[Installation / first-time setup](https://github.com/Wkrotik/OrBeats/blob/main/docs/getting-started.md)**

## What changed

- Guided setup for an existing library/retained template or, when needed, explicit
  one-time extraction of your own base-game schema. Validated local templates are
  reused; unnecessary extraction is disabled. Pending temporary settings must be
  restored before setup is complete.
- Prominent activity panel above setup instructions, with current step, elapsed
  time and an indeterminate loading bar. No invented percentage; reduced motion
  and late-status/error handling are covered.
- Template checking runs native validation in a separate process, keeping the
  local server responsive. Byte-backed asset loading avoids Windows file-handle
  cleanup failures. Installation and setup diagnostics are saved in bounded logs.
- Explicit, conservative recovery for an empty abandoned installation lock after
  all writers stop, the game closes and readable stable state is archived. No
  automatic lock deletion, song deletion or retry.
- Disable unused native file-drop hooks in both desktop windows to fix the
  reproduced Wine/Bottles OLE startup crash. No sandbox/GPU workaround or binary
  patch is shipped; ordinary DOM drag/drop is retained.

## Versions and downloads

Desktop **0.1.20**, web interface **0.7.36**, pipeline **0.5398**.
Main **0.8079** and Extras **0.0015** are unchanged from 0.1.16 and bundled with both
apps; separate PRX files are available for manual management. Windows installers
remain unsigned. Normal users do not need the sources/notices archive.

Requires **CUSA12878 / patch 2.04**, GoldHEN plugin support and FTP. Fully close
Beat Saber for writes. OrBeats never launches/closes the game for you, bundles
proprietary game assets, replaces stock/DLC songs or bypasses entitlements.

## Validation and limits

The Windows installer is the exact CI build tested by the owner in Bottles; it
has not been rebuilt for publication. Source commit:
`a83d7424ed8626c2c46f73c06e308a12c890dd03`.
[Successful native Windows CI](https://github.com/Wkrotik/OrBeats/actions/runs/41322508993).

Local host: 2,067 tests passed; curated source: 1,218 passed; actual frozen Linux
helper: 61 passed; native Rust: seven passed. Native Windows checks cover private
bootstrap/STOP, codecs at 44.1/48 kHz, real nested pipeline/setup workers and
mocked fresh-library/recovery behavior. Linux passed the 467-ELF GLIBC <=2.35 audit,
actual isolated AppImage startup/close and full frozen conversion/readback.

The actual source-built Windows app also rendered setup in a network-isolated
Bottles copy without changing the original bottle. The owner reports it works
in Bottles; this is not a blanket Wine compatibility guarantee. A completely
fresh-console raw-stock extraction and every hardware configuration have not
been independently validated. No PS4 writes were performed during release work.

The sidebar's misleading web-interface version label remains unchanged in these
binaries; its removal is queued separately for the next release.

Verify downloads with **SHA256SUMS**. Source, notices and exact dependency-source
inventories are in `OrBeats_0.1.20_sources-notices.tar.gz`; application source is
also available under the release tag.
