# OrBeats 0.1.16 — first-time setup fix and updated Extras

## Fixes

- Fix [issue #1](https://github.com/Wkrotik/OrBeats/issues/1): a console without a
  library manifest no longer triggers a missing development-fixture error in the
  packaged Windows or Linux app. Production compatibility metadata preserves
  existing legacy libraries; absent files are not advertised as installed songs.
- Missing remote directories must be proven absent through readable ancestor
  listings. Unreadable existing files/directories, incomplete legacy libraries,
  retained manifest backups and unrecognized song files still require recovery;
  the app does not reset them or overwrite them as a fresh installation.
- Test connection now tests the IP currently entered in the form, independently
  of saving settings or reading the song library. Enter the IP only, without
  `:2121`; GoldHEN FTP port 2121 and anonymous access are set automatically.
  Save connection is still required to apply the address to installations.

## Extras 0.0015

- Bundle the updated Extras plugin in both desktop apps and as the standalone
  `orbeats_extras.prx` download. It hides the identified main-menu music-pack
  promotion/banner and its button while retaining health auto-dismiss and the
  read-only top-ten ScoreSaber display. No stock/DLC catalogue, entitlement,
  ownership or store changes.
- This version retains the feature set hardware-confirmed in 0.0010 and removes
  unsuccessful experimental saber-offset work from 0.0011–0.0014. There are no
  saber-offset controls/hooks/settings. This is not a claim of independent
  hardware validation of the newly packaged 0.0015 build.
- Main OrBeats plugin remains 0.8079. Existing users need not reinstall it to
  obtain the app fix. To obtain promotion hiding, explicitly install/update
  Extras with Beat Saber fully closed and GoldHEN FTP running.

## Downloads and verification

Download only the app for your platform for normal use. The desktop bundles
include both plugins; standalone PRXs are provided for manual installation.
`release-manifest.json` supports update checks; `SHA256SUMS` allows download
verification. One labelled sources-and-notices archive contains the curated
third-party sources, licences, build recipes and provenance.

The Windows installer is unsigned. Automated native Windows checks include
both audio rates, packaged-runtime fresh-library regression, backend bootstrap,
shutdown and installer generation; there is no hands-on Windows GUI/upgrade/
uninstall test claim. Linux verification targets the Ubuntu 22.04 baseline,
not every distro/FUSE/Wayland setup. Previously reported optional Linux cursor,
ATK and GStreamer warnings are not fixed or suppressed by this patch. No console
writes or game launches are performed by release validation.
