# OrBeats installation

The current installation and first-time setup guide is maintained in
**[Installing and setting up OrBeats](getting-started.md)**.

It covers Windows/Linux installation, Bottles startup, connection and plugins,
existing-template reuse, one-time extraction and restoration, the setup activity
panel, song installation, updates, explicit lock recovery and private logs.

Download the app from the official [latest release](https://github.com/Wkrotik/OrBeats/releases/latest).
